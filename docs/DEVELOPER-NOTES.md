## Continuation status

The selected reference is official LTX Desktop 1.3.2 with five pinned LTX-2.5 Fast BF16 model files. The six artifacts total 71,955,233,680 bytes. The last access check could reach the installer. The local runner lacked Hugging Face authentication for the five model files and issued no authenticated file requests. The pilot remains **NOT RUN**. No generation time, peak inference memory, output quality or Q8 comparison has been measured for this pilot.

A successful future result requires a playable derivative, independent boundary review and source integrity evidence. The stock Extend request lacks a per-job custom adaptation input. Any engine-selection or adaptation decision requires its own evidence. See the [pilot inputs and evaluation rules](NATIVE-FILE-REFERENCE.md#continuation-experiment).
